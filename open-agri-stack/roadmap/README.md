# Roadmap

Designs for what comes next in Agri Stack, beyond what is built. Each page says what is decided and what is open; the full list of what is left is in [TODOs & Open Items](../open-items/README.md).

| Page | Covers |
| --- | --- |
| [Data Sharing Gateway](data-sharing-gateway.md) | The Exchange as a generic gateway: stacks as packs, standard-aware connectors per registry, use cases written by administrators |
| [Interoperability with OAN (Beckn)](oan-interoperability.md) | The Composite as a provider node on the Open Agri Network |
| [Livestock Registry](livestock-registry.md) | An Animal register and a livestock events register, and how they relate to the Farmer Registry |
| [Registry Data Sync](registry-data-sync.md) | Registries sharing data with each other, e.g. crop activity kept in the Farmer Registry |

For both register kinds, one verification model and one correction model are designed in the Registry Platform: [Verification and Correction](../../products/registry/registry/design/verification-and-correction.md).
