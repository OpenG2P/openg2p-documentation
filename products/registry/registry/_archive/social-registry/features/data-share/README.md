# Data Sharing

Today, SR offers an API-based data sharing mechanism. Data from Social Registry can be shared with external entities in the following ways:

* CSV
* [Search APIs](../../developer-zone/api/search-apis.md)
* [CRUD APIs](../../developer-zone/api/individual-apis.md)
* [via IUDX](../../../../../../../data-share/openg2p-iudx.md)
* [via WebSub](data-sharing-websub/)
