# Versions

Every image and the Helm chart built from a commit carry the **same** version,
derived from git by the central pipeline — so a chart version tells you exactly
which images it deploys.

{% hint style="info" %}
**Changelog — every released version and what changed in it:**
[**registry-disability-registry changelog**](https://openg2p.github.io/versions/disability-registry/CHANGELOG.html)

All OpenG2P components are indexed at
[**openg2p.github.io/versions**](https://openg2p.github.io/versions/).
These are generated by CI on every publish and are the single source of truth —
versions are not listed on this site.
{% endhint %}

## Two version lines

This registry's version and the platform's move independently:

* **This registry's version** — the wrapper chart and its five images, locked
  together and stamped by CI on every commit.
* **Platform version** — the `openg2p-registry` chart and images it extends,
  pinned deliberately and changed as a pair. See the
  [Registry Platform changelog](https://openg2p.github.io/versions/registry-platform/CHANGELOG.html).

How versions are derived, frozen and promoted is documented org-wide in
[Helm & Docker Versioning Strategy and CI](https://docs.openg2p.org/operations/deployment/helm-docker-versioning-and-ci).
