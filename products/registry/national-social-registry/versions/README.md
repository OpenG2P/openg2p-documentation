# Versions

The National Social Registry publishes its own Docker images and Helm chart. Every image and the chart built from a commit carry the **same** version, derived from git by the central pipeline — so a chart version tells you exactly which images it deploys.

{% hint style="info" %}
**Changelog — every released version and what changed in it:**
[**openg2p-packaging/national-social-registry/CHANGELOG**](https://openg2p.github.io/openg2p-packaging/national-social-registry/CHANGELOG)

This is generated by CI on every publish and is the single source of truth. Versions are no longer listed on this site.
{% endhint %}

## What is published

| Artifact | Where |
|---|---|
| Helm chart `openg2p-nsr` | [`openg2p.github.io/openg2p-helm`](https://openg2p.github.io/openg2p-helm) |
| Docker images `openg2p/openg2p-nsr-*` | Docker Hub |

## The two version lines

The NSR version and the platform version move independently:

* **NSR version** — the wrapper chart and the NSR images, locked together, stamped by CI on every commit.
* **Platform version** — the `openg2p-registry` images and chart the NSR extends, **hardcoded** in `RP_VERSION` (each Dockerfile) and in the chart dependency, and changed deliberately as a pair. See the [Registry Platform changelog](https://openg2p.github.io/openg2p-packaging/registry-platform/CHANGELOG).

How versions are derived, frozen and promoted is documented org-wide: [Helm & Docker Versioning Strategy and CI](https://docs.openg2p.org/operations/deployment/helm-docker-versioning-and-ci).

{% hint style="warning" %}
**This supersedes the previous scheme**, in which the NSR chart version was derived from the branch name by a separate `helm-publish.yml` workflow, independently of the Docker image tags. Chart and images are now versioned together, one version per commit.
{% endhint %}
