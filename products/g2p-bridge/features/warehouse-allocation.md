# Warehouse Allocation

#### Allocate Distribution Warehouses

Assign warehouses to geographic zones for commodity distribution.

#### Respect Warehouse Authorization

Only allocate warehouses authorized to store and distribute specific program/benefit commodities.

#### Respect Warehouse Geographic Coverage

Only allocate warehouses serving the beneficiary's geographic area.

#### Distribute Among Eligible Warehouses

Select warehouses from eligible options for balanced commodity distribution.

#### Allocate Based on Benefit Type

Allocate warehouses only for commodity and combined benefit programs (not for cash-only).
