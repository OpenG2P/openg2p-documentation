# Enrolment workflow

An enrolment cycle follows the following steps, as shown in the diagram below.

{% embed url="https://miro.com/app/board/uXjVIgk77Mw=/?share_link_id=578340558442" %}

Once you approve a list as "Approved for Final Enrolment", the enrolment cycle is deemed complete. You cannot create any more beneficiary lists under that cycle. This approved beneficiary becomes the basis of all future disbursements till a new beneficiary list is created and approved in a fresh Enrolment cycle.&#x20;
