# Developer Zone

Resources for developers building on, extending, or running the G2P Bridge locally.

* [Testing](testing/README.md) — the regression **Sanity Suite** (in-cluster smoke + e2e) and the **API Walkthrough** (Postman).
* [Developer Install](developer-install/README.md) — run the Bridge and the Example Bank from source on Linux.
* [API Reference](api-reference.md) — the Partner and Example Bank API specs.
* [Technology Stack](technology-stack.md) — languages, frameworks and infrastructure.

For the internal design, see [Design](../../products/g2p-bridge/design-specifications/README.md). To build custom connectors/resolvers, see [Extensions](../../products/g2p-bridge/tech-guides/README.md).
