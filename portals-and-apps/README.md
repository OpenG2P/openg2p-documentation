# Portals & Apps

OpenG2P provides web-based portals for different user personas to interact with the platform.

| Portal | Audience | Purpose |
| --- | --- | --- |
| **Staff Portal** | Programme staff & administrators | Manage registrants, programmes, payments, and system configuration |
| **Beneficiary Portal** | Registrants & beneficiaries | Self-service registration, application tracking, and profile management |
