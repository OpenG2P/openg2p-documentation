# Integration with Sponsor Banks

For programs involving cash transfers, PBMS can be configured to send payment instructions directly to sponsor banks. This feature ensures that payments are streamlined and automated. Additionally, PBMS provides extension packs that allow implementation teams to customize the bank integration interface, making it adaptable to different banking systems and practices.
