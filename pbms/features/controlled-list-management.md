# Controlled List Management

Beneficiary lists in PBMS are always generated from registry data, ensuring consistency with the source registry. Users cannot directly edit enrolment or disbursement lists. Instead, any changes must first be made in the registry itself, after which PBMS can generate a new list. While PBMS allows the creation of multiple lists within a cycle, only one list can be approved in any given enrolment or disbursement cycle. Once a list has been approved, no further lists can be created for that cycle, thereby preserving data integrity and program control.
