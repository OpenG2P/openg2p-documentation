# Requirements



1. Data into OpenG2P Registry - can come from multiple sources
2. Multiple sources - Staff Portal, Beneficiary Portal, Agency App, Other Registries
3. Multiple sources - Staff Portal, Beneficiary Portal, Agency App, Other Registries
4. Multiple schemas - Standards, Custom
5. Multiple standards - DCI etc.
6. Multiple philosophies - DCI notifications - the spec only gives Event with ID, To use the event, it expects the receiver to invoke the Search API on the source with the ID
7. Asynchronous, scale-out, high volume, high throughput
8. Traceability all the way from raw incoming message to change log to register with appropriate linkages
9. Auditability
10. Error handling and retries
