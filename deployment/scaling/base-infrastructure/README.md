# Base Infrastructure

The base infrastructure of the V4 deployment architecture consists of the components that need to be installed in the sequence given below. &#x20;

* [Wireguard bastion](wireguard-bastion/)
* [NFS server](nfs-server.md)
* [Rancher cluster ](rancher.md)(observation cluster)
* [OpenG2P cluster](openg2p-cluster/)
* [Load Balancer](load-balancer/)
